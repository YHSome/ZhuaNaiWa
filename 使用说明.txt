宣传片怎么录（约 30 秒）
------------------------
1. 浏览器打开 promo\index.html（或线上 /promo/），按 F11 全屏
2. 点「开始播放」→ 3-2-1 倒计时后自动播放 30 秒
   BGM 是这份 HTML 用 WebAudio 现场合成的（无外部音频、无版权问题）
3. 用系统录屏（Win+G / OBS / QuickTime）录整个窗口即可
4. 空格暂停/继续、R 重播；底部控制条在舞台之外，录完裁掉那 46px 即可
   舞台固定 1920×1080 等比缩放，想 1:1 就把窗口拉到 ≥1920×1126

怎么玩
------
双击本目录下的 index.html（Chrome / Edge / Firefox 都行），不需要启动任何服务。

开局是「选关界面」：4 个关卡 + 无尽模式按麻将牌样式排开，
第 1 关默认解锁，通关后自动解锁下一关；已通关的关卡右上角有 ✔，格子下方显示评星与最快用时。
无尽模式在通关第 4 关（挑战关）后解锁。
进度存在浏览器本地（localStorage），下次打开会接着上次的解锁进度。

无尽模式（通关第 4 关后解锁）
----------------------------
· 清空一座麻将塔马上起下一座：第 1 塔 3 层 / 81 张，每清一塔再高一层（最高 6 层 162 张）
· 塔越高托盘越紧：第 1~2 塔 9 格，第 3 塔起收到 8 格（用不到的槽位会画成钉死的木条）
· 一条命：托盘满一次挑战就结束，不能重来、也不能把某一塔重新开始；时间一路累计
· 每塔清空后有 4 秒过渡页（显示本塔/下一塔规模与最高纪录），可点「继续爬塔」或「结束挑战」
· 最高塔数记在选关界面的无尽模式格子里；矮屏（高度 < 620px）会自动把塔高压到 4 层，保证放得下
· 实测反常识的一点：**光把塔堆高并不会更难**——9 种图案下牌越多越好凑三，
  最优解托盘峰值基本不随张数上升（54 张 8.2 → 81 张 7.6 → 162 张 8.6，都在 8 格上下）；
  真正拉高难度的是**收窄托盘**：同一副 81 张的牌，9 格可解率 80%、8 格 40%、7 格 30%

界面说明
--------
选关界面    点关卡直接开打；「继续游戏」回到当前牌局；「玩法说明」；「重置进度」
            标题下会显示总星数（共 12 颗）；无尽模式是整行的火系横幅格子
顶部 HUD    ☰ 选关 / 当前关卡（无尽模式显示「无尽 第 N 塔」）/ 剩余牌数 / 用时 / 🔊 音效开关；
            HUD 下方的细条是进度条，随清掉的牌变长，过关时拉满
底部木槽    9 个凹槽一眼看清还剩几格；占用接近上限时凹槽转橙、木槽描边发光，
            并浮出「只剩 N 格！」提示；再满一格转红、呼吸加速（无尽模式收窄托盘时，
            用不到的槽位画成钉死的木条）
过关面板    显示评星（按用时给 3/2/1 星）·用时·剩余·已解锁，按钮：下一关 / 重玩本关 / 选关
难度飙升    ★ 点「下一关」不会直接切关 ★，先弹过渡页：
            对比下一关的「图案种类 / 方块总数 / 托盘容量」并点亮难度点，
            倒计时 3 秒自动开战，也可以立刻点「开战！」或改去「选关」
            第 4 关通关后的过渡页是「无尽模式」说明页（第 1 塔规模 / 每清一塔的变化 / 一条命）
失败面板    托盘塞满时弹出（已替换掉浏览器原生 alert，不会再打断页面）
            按钮：重玩本关 / 选关；无尽模式则是「挑战结束」面板（爬塔数 / 清除张数 / 总用时）

发牌公平性（本轮的"隐形"优化）
------------------------------
每关发牌后，脚本会先读一遍牌面布局，重建"谁压着谁"的依赖图，再用多种贪心策略试着
把整副牌走一遍（详见 sheep-candidates\endless-scale.mjs / validator-check.mjs）：

  · 依赖图是**照游戏规则**建的：高一层、且横向/纵向相距 ≤40px 的牌压住它；
    另外还额外算了两种"游戏状态里没写、但玩家点不到"的情况：
      - 隔层正好盖住这张牌中心的牌（点击会被上层那张接走）
      - 同一层里坐标完全重合的两张牌（DOM 顺序靠后的画在上面）
  · 贪心求解器 6 个种子都走不通 → 判"不可解" → 自动重发（最多 6~8 次）
  · 重发只在开局几秒内、且玩家还没动手时进行；一旦你抓了第一张牌，牌面就锁死不动
  · 实测：第 4 关（9 种 / 54 张）原生发牌里求解器能走通的比例约 60%~83%
    （9 格托盘的最优解峰值均值就有 7.4/9——本来就贴着上限，所以"按刁度重发"这条已关掉，
     否则只会把能打通的紧牌换成松牌，越换越简单）
  · 验证脚本里 __NAIWA_SOLVE__ / __NAIWA_STATS__ 能看到每副牌的判定结果，
    __NAIWA_HINT__ 能要到当前局面的一条完整解法（回归测试就是照着它清塔的）

牌堆自适应缩放
--------------
塔的层数越多，牌堆以牌桌中心为圆心向外长。发牌后脚本量一次牌堆的实际包围盒，
按"进度条下方 ~ 道具行上方"这段可用区间反解出合适的缩放比（面板 1.18/桌面 1.32 为基准，
最多缩到 0.5）。这样 6 层 162 张的塔在手机上也不会顶到 HUD、压到道具行，更不会被顶栏按钮吃掉点击。
（回归测试里 8 种尺寸 × 3 种视口都验了：牌堆在安全区内、且没有被 UI 挡住的牌）

手机端适配
----------
· 轻点即选：加了「轻点 → click」兜底。有些浏览器会吞掉轻点（iOS 对带 :hover 样式的元素
  第一次只触发 hover、部分安卓 WebView 不补 click），现在触摸抬起后 200ms 没等到 click
  就自己补发一个，一次轻点只抓一张（迟到的真 click 会被丢弃，不会抓两张）
· 触屏不产生 hover 效果（hover 规则只在真鼠标设备下生效），图片长按也不再弹系统菜单
· 触感反馈：抓牌轻震 9ms、消除震两下、托盘告警震三下（手机浏览器支持 vibrate 时才生效）
· 触控目标够大：顶栏按钮 38px、面板主按钮 46px，关卡格子最小 92px 高
· 窄屏 320px：托盘自动从 330px 收窄到 294px，不会溢出屏幕
· 全面屏安全区：顶栏、弹窗、底部木槽都会避开刘海/小黑条
· 横屏（高度 ≤ 520px）：自动隐藏大标题、关卡横排成一行、面板压缩到 263px 高，
  按钮不会再被挤到屏幕外
· 键盘可达：Tab 能走到所有按钮与关卡格子，有蓝色 focus 描边；aria-label 标了关卡状态

关卡与难度
----------
  1 教程关   3 种图案 ·  9 张   怎么点都不会输（3 种图案时托盘最多囤 6 张）    3★ ≤8s   2★ ≤16s
  2 轻松关   4 种图案 · 24 张                                            3★ ≤22s  2★ ≤42s
  3 进阶关   6 种图案 · 36 张                                            3★ ≤45s  2★ ≤80s
  4 挑战关   9 种图案 · 54 张   全部素材上场，容易塞满托盘                 3★ ≤75s  2★ ≤140s
  5 无尽模式 9 种图案 · 81~162 张  通关第 4 关解锁，一条命爬塔（见上方"无尽模式"）   无评星
托盘共 9 格（无尽模式第 3 塔起收到 8 格），塞满且无法消除即失败。

关于音效与背景音乐（原创，无第三方权利）
----------------------------------------
音效（5 个）和背景音乐（1 首）全部由脚本按纯数学方式合成，不含任何采样素材：

  click.wav    0.10s  抓牌：木质轻响
  drop.wav     0.24s  落牌/消除：牌撞牌的"咔" + 一点点闷响
  win.wav      1.05s  过关：上行琶音 + 铃音泛音
  lose.wav     0.95s  失败：下行三音 + 低闷音
  welcome.wav  1.20s  开局：三声木质招呼音
  bgm.wav      18.46s 背景音乐：8 小节无缝循环（104BPM，A 小调五声音阶，Am-F-C-G）

背景音乐怎么做的：
  · A 小调五声音阶，古筝/木琴感的拨弦 + 暖垫 + 轻拨低音 + 沙锤 + 高音铃
  · 织体和声有呼吸感：前 2 小节只留垫音当引子，中段进旋律与低音，末小节收干净再回到引子
  · 循环点：所有音符在结尾自然衰减到接近 0（实测首尾振幅 0.001/0.0002），不会"咔"一下
  · 音量刻意压在音效之下（游戏里 0.34，音效 1.0）；过关/失败时会短暂让路，不盖住音效
  · 切到后台自动暂停，回来续播；右上角 🔊 是一键静音（音效 + 音乐）

想改音色/时长/编曲：编辑 sheep-candidates\make-bgm.mjs（乐谱就在文件里）
  node sheep-candidates\make-bgm.mjs
会同时输出逐小节 RMS / 起音数 / 循环点自检，以及一张整段波形图。
注意：输出目录是构建源 sheep-candidates\xlegex-patched\audio\，
改完要重新打包才会进到游戏根目录的 audio\（打包脚本会先清空再拷贝）。

音效改色/时长：编辑 sheep-candidates\make-sfx.mjs 后跑
  node sheep-candidates\make-sfx.mjs sheep-candidates\sfx
会同时输出 sfx\waveform.svg 波形对照图。

改完怎么验
----------
  node sheep-candidates\patch-dist.mjs
      给构建产物打补丁（幂等，跑第二遍显示"已应用"）：大标题改「抓奶蛙」、
      托盘容量改成读 window.__NAIWA_CAP__（无尽模式靠它收窄槽位）、注入无尽模式开局入口

  node sheep-candidates\build-portable.mjs sheep-candidates\xlegex-patched .
      重新打包 index.html（会按 asset-usage.json 自动跳过用不到的素材图）

  node sheep-candidates\regress.mjs
      回归测试 24 项：品牌名一致 / 图片不裂 / 三种视口的 HUD+进度条遮挡 /
      托盘与槽位对齐（槽位节距=牌节距、首槽=首牌）/ 轻点恰好抓一张 / 槽位占用同步 /
      进度条数值 / 三消粒子生成与回收 / 过关评星存档 / 进度条拉满 /
      难度飙升流转 / 矮屏塔高限制 / 大牌堆自适应缩放（8 种尺寸 × 3 视口）/
      第 4 关发牌门槛 / 托盘告警 / JS 报错
      （需要先起一个带 --remote-debugging-port 的无头浏览器，脚本注释里有命令行）

  node sheep-candidates\endless-check.mjs
      无尽模式专项 11 项：署名行隐藏 / 无尽模式格子 / 第 1 塔规模 / 难度曲线 /
      槽位容量对可解率的影响 / 清塔 → 过渡页 → 自动开下一塔 → 塞满结束
      （清塔是严格照求解器给的完整解法走的，每一步都校验"要抓的那张确实被拿走了"）

  node sheep-candidates\endless-scale.mjs
      难度标定：同一副牌分别按 9/8/7/6 格判可解性，输出各层数的可解率与最优解峰值

  node sheep-candidates\hint-diag.mjs
      调试用：逐层打印"模型里的可点牌数 vs 真实 DOM 里没 mask 的牌数"，可解性判定不准时用它定位

  node sheep-candidates\asset-scan.mjs
      重跑一遍资源用量扫描（跑完覆盖 asset-usage.json，再打包就会用新的清单）
